# Photo Finish

Photo Finish processes batches of JPG/JPEG, PNG, TIFF, BMP, WebP, GIF, and AVIF images (when the installed Pillow build supports the format). It can add a solid-color canvas or border, optionally downsize photos, and save PNG or JPEG output. Original photos are left in place; existing outputs are skipped. HEIC/HEIF and non-JPEG multi-frame images are not supported in this version.

## Use

1. On Windows, run `setup.bat` once if you plan to use the Python version, then run `launch.bat`. If you have `photo-finish.exe`, open it directly.
2. Choose an **Input** folder and either select an **Output** folder or check **Output folder beside input**. With the box checked, the Output field is disabled and displays a sibling folder named from the input folder plus the image suffix: `Photos` with `_finished` writes to `Photos_finished`. Changing the input or suffix updates that folder. Unchecking restores the manual output choice. A nonempty suffix is required for automatic output. If that sibling folder already exists, existing output files are skipped; the app never deletes them. Select **Include subfolders** to scan subfolders and keep their structure in the output.
3. **Border mode** starts selected with 100 px on all four sides. Enter pixel margins to add around each photo. **Same top and bottom** and **Same sides** begin checked; bottom and right follow the corresponding fields until you uncheck them. This mode determines output size from each photo and its margins.
4. In **Canvas mode**, enter a target ratio and either width or height in pixels. The other dimension follows the ratio. Auto orientation turns the canvas to match each photo. **Expand canvas** starts checked so larger photos can fit. If you turn it off, any photo larger than the target canvas fails with a specific error; lossless mode cannot shrink it. If an expanded canvas has exactly the same dimensions as a photo, use Border mode to guarantee a visible margin.
5. Choose the fill color. **Lossless PNG** is checked by default and disables resizing and JPEG recompression. Decoded 8-bit RGB and RGBA pixels are preserved; palette and grayscale images are expanded to RGB/RGBA, and higher-depth or CMYK images require turning Lossless off for conversion. Transparent pixels remain transparent in PNG output; JPEG output fills transparency with the selected color. Uncheck Lossless to enable bicubic reduction or JPEG output. Reduction never upscales and can apply light sharpening after downsizing. JPEG output recompresses, and its quality slider controls the amount of compression.
6. Check **Print receipt** beside **Start batch** to open a receipt window when the run ends. It shows elapsed time, counts, before/after totals, space saved, and the settings used. Uncheck it to skip the window. The receipt has a **Copy receipt** button.
7. Use **Start batch** to process the folder. The preview shows the first JPG; the log shows each saved, skipped, or failed file. If files fail, the receipt shows common failure reasons and example filenames; the status line shows the first error when nothing was saved. **Cancel** stops after the current photo finishes.

The receipt's size totals compare only successfully saved files with their input files. A negative space saving means the output uses more space, which is common with PNG. EXIF orientation is applied before processing. Compatible RGB color profiles are copied; the optional EXIF setting may retain location data. If two inputs share a base name (such as `photo.jpg` and `photo.png`), the output names include their input extensions so neither is lost. The PNG file differs from a source JPG even when its decoded photo pixels are unchanged.

When a JPEG contains multiple picture frames, Photo Finish uses the first frame and records that in the preview, log, and receipt. Other frames are not exported.

If a file is rejected as unsupported image data, the per-file log and receipt show its detected format and first file bytes. The app detects image data independently of a supported filename's extension.
